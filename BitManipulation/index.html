Two's Complement & Java Bitwise Operators

Java integers are 32-bit signed integers stored using Two's Complement. To negate a number \(n\): invert all bits and add 1. \[-n = \sim n + 1\]

a & b (AND)

Returns 1 only where both bits are 1. Used for masking and checking bit presence.

a | b (OR)

Returns 1 if at least one bit is 1. Used for setting bits.

a ^ b (XOR)

Returns 1 if bits differ. Key properties: \(a \oplus a = 0\) and \(a \oplus 0 = a\).

a >> k vs a >>> k

>> preserves the sign bit (arithmetic shift). >>> always pads high bits with 0 (logical unsigned shift).

The 10 Essential Bit Manipulation Tricks

// 1. Check if number is odd or even:
boolean isOdd = (n & 1) != 0;

// 2. Check if k-th bit is set:
boolean isKthSet = (n & (1 << k)) != 0;

// 3. Set k-th bit to 1:
n = n | (1 << k);

// 4. Clear k-th bit to 0:
n = n & ~(1 << k);

// 5. Toggle k-th bit (0 -> 1 or 1 -> 0):
n = n ^ (1 << k);

// 6. Clear the lowest set bit (Brian Kernighan):
n = n & (n - 1);

// 7. Extract / Isolate the lowest set bit:
int lowestBit = n & (-n);

// 8. Check if n is a power of 2:
boolean isPowerOf2 = n > 0 && (n & (n - 1)) == 0;

// 9. Swap two variables without temporary variable:
a ^= b; b ^= a; a ^= b;

// 10. Turn off all bits except the lowest set bit:
int isolated = n & ~(n - 1);

Brian Kernighan's Algorithm

Subtracting 1 from an integer flips all bits from the rightmost set bit to the end. Therefore, n & (n - 1) turns off the lowest set bit in exactly one operation. 

public int hammingWeight(int n) {
    int count = 0;
    while (n != 0) {
        n &= (n - 1); // Clears lowest set bit in O(1)
        count++;
    }
    return count; // Loops ONLY as many times as set bits exist!
}

Bitmasking & Subsets Generation

An array of size \(n\) has \(2^n\) subsets. Each integer from \(0\) to \(2^n - 1\) in binary represents a unique subset configuration where bit \(i = 1\) signifies including \(arr[i]\). 

public static List<List<Integer>> subsetsBitmask(int[] nums) {
    int n = nums.length;
    int total = 1 << n; // 2^n subsets
    List<List<Integer>> res = new ArrayList<>();

    for (int mask = 0; mask < total; mask++) {
        List<Integer> subset = new ArrayList<>();
        for (int i = 0; i < n; i++) {
            if ((mask & (1 << i)) != 0) subset.add(nums[i]);
        }
        res.add(subset);
    }
    return res;
}
