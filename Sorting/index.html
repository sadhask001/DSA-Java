Key Algorithmic Concepts & Classifications

Comparison Lower Bound

Any comparison-based sort must differentiate among \(n!\) possible input permutations. A binary decision tree of height \(h\) has at most \(2^h\) leaves. Therefore: \[2^h \ge n! \implies h \ge \log_2(n!) = \Omega(n \log n)\] No comparison sort can beat \(\Omega(n \log n)\) in the worst case!

Algorithm Stability

A sort is stable if duplicate keys maintain their original relative order. For example, sorting students by grade after previously sorting by name keeps names alphabetical for equal grades. Merge and Insertion Sort are stable; Quick and Heap Sort are not.

In-Place Sorting

An algorithm is in-place if it requires \(O(1)\) (or \(O(\log n)\) stack frames) auxiliary memory beyond the input array itself. Quick Sort, Heap Sort, and Insertion Sort are in-place; standard Merge Sort requires \(O(n)\) extra buffer space.

Elementary O(n²) Sorting Algorithms

1. Insertion Sort (The Champion of Small Arrays)

Insertion sort maintains a sorted prefix \([0..i-1]\) and shifts elements greater than the key to make room. It performs remarkably well (\(O(n)\)) on nearly sorted arrays. Java's internal DualPivotQuicksort and Python's Timsort both switch to Insertion Sort whenever sub-array partition size falls below 32-47 elements. 

public static void insertionSort(int[] arr) {
    for (int i = 1; i < arr.length; i++) {
        int key = arr[i];
        int j = i - 1;
        while (j >= 0 && arr[j] > key) {
            arr[j + 1] = arr[j]; // shift right
            j--;
        }
        arr[j + 1] = key;
    }
}

2. Selection Sort & Bubble Sort

Selection Sort: Scans the unsorted suffix to pick the absolute minimum, swapping it into position \(i\). Performs exactly \(\frac{n(n-1)}{2}\) comparisons regardless of input distribution, but makes at most \(n - 1\) swaps (useful on EEPROM flash memories where write cycles are costly).

Bubble Sort: Repeatedly bubbles adjacent inversions to the end. Adding a boolean swapped flag allows it to terminate in \(O(n)\) time if no swaps occur during pass 1.

Advanced O(n log n) Divide & Conquer Algorithms

Merge Sort (Divide, Conquer, and Combine)

Divides the array into two halves until length 1, then merges the sorted halves using a temporary buffer. Recurrence relation: \(T(n) = 2T(n/2) + O(n) = O(n \log n)\) across all cases. 

public static void mergeSort(int[] arr, int left, int right) {
    if (left >= right) return;
    int mid = left + (right - left) / 2;
    mergeSort(arr, left, mid);
    mergeSort(arr, mid + 1, right);
    merge(arr, left, mid, right);
}

private static void merge(int[] arr, int left, int mid, int right) {
    int[] temp = new int[right - left + 1];
    int i = left, j = mid + 1, k = 0;

    while (i <= mid && j <= right) {
        if (arr[i] <= arr[j]) temp[k++] = arr[i++]; // <= guarantees STABILITY
        else temp[k++] = arr[j++];
    }
    while (i <= mid) temp[k++] = arr[i++];
    while (j <= right) temp[k++] = arr[j++];

    System.arraycopy(temp, 0, arr, left, temp.length);
}

Quick Sort (Partitioning Powerhouse)

Picks a pivot and partitions the array such that all elements \(< \text{pivot}\) lie on the left and all \(\ge \text{pivot}\) lie on the right. Outstanding average cache performance because operations are strictly local and in-place. 

public static void quickSort(int[] arr, int low, int high) {
    if (low < high) {
        int pi = partition(arr, low, high);
        quickSort(arr, low, pi - 1);
        quickSort(arr, pi + 1, high);
    }
}

private static int partition(int[] arr, int low, int high) {
    int pivot = arr[high];
    int i = low - 1;
    for (int j = low; j < high; j++) {
        if (arr[j] < pivot) {
            i++;
            swap(arr, i, j);
        }
    }
    swap(arr, i + 1, high);
    return i + 1;
}

Non-Comparison Linear O(n) Sorts

By bypassing pairwise comparisons, these algorithms break the \(\Omega(n \log n)\) theoretical barrier when keys satisfy mathematical assumptions:

Counting Sort

Calculates element frequencies into a count array of size \(k = \max - \min + 1\), transforms it into running prefix sums to know the exact target indices, and copies elements backwards to ensure stability. Runs in \(O(n + k)\) time. 

public static void countingSort(int[] arr) {
    if (arr.length <= 1) return;
    int max = Arrays.stream(arr).max().getAsInt();
    int min = Arrays.stream(arr).min().getAsInt();
    int range = max - min + 1;

    int[] count = new int[range];
    for (int num : arr) count[num - min]++;
    for (int i = 1; i < range; i++) count[i] += count[i - 1]; // prefix sums

    int[] output = new int[arr.length];
    for (int i = arr.length - 1; i >= 0; i--) {
        output[--count[arr[i] - min]] = arr[i];
    }
    System.arraycopy(output, 0, arr, 0, arr.length);
}
