Mastering Recursion & Backtracking

Recursion breaks complex problems down into self-similar sub-problems, unwinding decisions across JVM stack frames. Backtracking supercharges recursion with exhaustive tree search and intelligent branch pruning: Choose, Explore, and Unchoose.

The Anatomy of a Recursive Function

Every valid recursive method is defined by two mandatory invariants:

1. The Base Case (Termination)

The condition where the subproblem is small enough to solve directly without further recursive calls. Omitting or erroneously framing the base case causes infinite stack descent, triggering JVM StackOverflowError.

2. The Recursive Step (Progress)

The self-call with transformed arguments that strictly converges toward the base case (e.g. \(n - 1\), \(\lfloor n / 2 \rfloor\), or moving to child pointer).

Under the Hood: The JVM Call Stack

Each method invocation allocates an Activation Record (Stack Frame) on the thread's call stack. A stack frame stores:

  • Method Parameters passed by value.
  • Local Variables initialized within the scope.
  • Return Address: pointer in bytecode bytecode where execution resumes after return.
  • Return Value evaluated back to the caller frame.

StackOverflowError: By default on 64-bit JVMs, thread stack size is 1024 KB (configured with -Xss). A recursive depth exceeding ~10,000 frames typically causes a stack overflow!

The Universal Backtracking Framework

Backtracking is Depth-First Search on a conceptual State Space Tree. When a branch cannot lead to a valid solution, we prune it and backtrack (revert state) to try the next alternative. 

// The Universal Choose - Explore - Unchoose Template
void backtrack(State state, List<Solution> results) {
    if (isGoal(state)) {
        results.add(new ArrayList<>(state.current)); // DEEP COPY snapshot
        return;
    }

    for (Choice choice : state.getAvailableChoices()) {
        if (isValid(choice, state)) {
            // 1. CHOOSE (Mutate state)
            state.apply(choice);

            // 2. EXPLORE (Recursive DFS descent)
            backtrack(state, results);

            // 3. UNCHOOSE (Revert state mutation for next branch)
            state.undo(choice);
        }
    }
}

Canonical Problem Archetypes

1. Subsets / Power Set (\(O(2^n)\))

At each index \(i\), binary decision: either Include candidate \(nums[i]\) or Exclude it. To handle duplicates without duplicate sets (Subsets II), sort the array first and skip when i > start && nums[i] == nums[i-1].

2. Permutations (\(O(n!)\))

Order matters. Generate all arrangements of \(n\) items. Use a boolean array boolean[] visited to track items currently inside the partial permutation.

3. Constraint Satisfaction (N-Queens & Sudoku)

In N-Queens, place a queen in row \(r\) only if no previously placed queen shares the same column \(c\), main diagonal \((r - c)\), or anti-diagonal \((r + c)\). Prune immediately on collision!

Complete Java Implementations

N-Queens (Bitmask Optimized Backtracking)

public class NQueensSolver {
    public List<List<String>> solveNQueens(int n) {
        List<List<String>> solutions = new ArrayList<>();
        char[][] board = new char[n][n];
        for (char[] row : board) Arrays.fill(row, '.');

        backtrack(0, n, board, new boolean[n], new boolean[2 * n], new boolean[2 * n], solutions);
        return solutions;
    }

    private void backtrack(int r, int n, char[][] board,
                           boolean[] cols, boolean[] diag1, boolean[] diag2,
                           List<List<String>> res) {
        if (r == n) {
            List<String> snapshot = new ArrayList<>();
            for (char[] row : board) snapshot.add(new String(row));
            res.add(snapshot);
            return;
        }

        for (int c = 0; c < n; c++) {
            int d1 = r - c + n; // main diagonal index
            int d2 = r + c;     // anti diagonal index
            if (cols[c] || diag1[d1] || diag2[d2]) continue; // PRUNE

            board[r][c] = 'Q';
            cols[c] = diag1[d1] = diag2[d2] = true;   // CHOOSE

            backtrack(r + 1, n, board, cols, diag1, diag2, res); // EXPLORE

            board[r][c] = '.';
            cols[c] = diag1[d1] = diag2[d2] = false;  // UNCHOOSE
        }
    }
}
