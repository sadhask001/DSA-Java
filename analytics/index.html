Privacy Notice & Architecture Setup

1. Privacy-Conscious Principles

This platform is designed to respect visitor privacy by default:

  • Zero Cookies: No persistent tracking cookies or cross-site tracking tags are stored.
  • No Personal Data: No passwords, form inputs, emails, or personal identification is collected.
  • No IP Storage: Full IP addresses are never transmitted or saved in custom telemetry payloads.
  • No Invasive Tracking: Mouse movements, keyboard keypresses, and window focus changes are not tracked.
  • Do Not Track: If your browser sends the DNT: 1 header, all telemetry is disabled automatically.

3. GitHub Pages Static Site Architecture

Because this site is hosted on GitHub Pages, there is no server-side database on this domain. By default, telemetry events are stored safely in your browser's localStorage for demonstration and local tracking.

To aggregate global metrics across all visitors without compromising administrative security, configure a hosted backend such as Supabase using Row Level Security (RLS): 

-- 1. Create table for public events
CREATE TABLE website_activity_events (
  id uuid DEFAULT gen_random_uuid() PRIMARY KEY,
  created_at timestamptz DEFAULT now(),
  event_type text NOT NULL,
  page_path text,
  page_title text,
  session_id text,
  topic text,
  question_id text,
  difficulty text,
  platform text,
  details jsonb
);

-- 2. Enable Row Level Security (RLS)
ALTER TABLE website_activity_events ENABLE ROW LEVEL SECURITY;

-- 3. Policy: Public visitors can ONLY INSERT records
CREATE POLICY "Allow public insert only"
  ON website_activity_events
  FOR INSERT
  TO anon
  WITH CHECK (true);

-- 4. Policy: ONLY authenticated owners can SELECT or read records
CREATE POLICY "Allow authenticated owner read only"
  ON website_activity_events
  FOR SELECT
  TO authenticated
  USING (true);

After setting up your Supabase project, simply add your public project URL and public anon key into shared/js/analytics-config.js. Never put your service-role key in public files!
