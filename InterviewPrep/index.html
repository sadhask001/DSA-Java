Company Specific Interview Profiles

Each Tier-1 tech company emphasizes distinct problem types, interview styles, and evaluation criteria:

Google
Focuses on original, unseen graph modeling, Union-Find, Segment Trees, and complex DP state spaces. Expects scalable algorithmic purity without brute-forcing.
  • Topological Sort & Dijkstra
  • Tree DP & State Machine DP
  • Strict Asymptotic Correctness
Amazon
Focuses heavily on Trees, Heaps/PriorityQueues, BFS/DFS 2D Grids, and customer-facing scenarios. Equal 50/50 weight placed on 16 Leadership Principles (STAR method).
  • 2D Grid BFS / Island Problems
  • PriorityQueue (Top K / Median)
  • Leadership Principle Alignment
Meta
Extreme emphasis on coding speed and syntactic correctness. Typically requires completing two Medium problems in 40 minutes with clean edge-case handling.
  • Two Pointers & Sliding Window
  • Lowest Common Ancestor (LCA)
  • Rapid Bug-Free Execution
Microsoft
Emphasizes fundamental data structures: Linked Lists, BSTs, String manipulations, and defensive engineering practices against null and memory hazards.
  • Linked List manipulation in-place
  • BST Traversals & Validations
  • High defensive coding standards
