Mastering Dynamic Programming

Dynamic Programming is the art of solving complex optimization problems by caching subproblem solutions to prevent exponential recomputations. Turn \(O(2^n)\) brute force recursions into blazing \(O(n)\) polynomial algorithms through memoization, tabulation, and rolling array compression.

The Two Mandatory Pillars of Dynamic Programming

1. Overlapping Subproblems

A problem exhibits overlapping subproblems when a recursive algorithm visits the exact same subproblem repeatedly instead of generating fresh subproblems (unlike Divide and Conquer, which partitions into disjoint subsets like Merge Sort).

2. Optimal Substructure

An optimal solution to the overall problem can be constructed from optimal solutions to its constituent subproblems. For example, the shortest path from \(A\) to \(C\) via \(B\) is the shortest path \(A \to B\) combined with \(B \to C\).

Top-Down (Memoization) vs Bottom-Up (Tabulation)

Top-Down Memoization

Preserves intuitive natural recursive thinking. Checks if memo[n] != null before solving. Solves only strictly required subproblems, but consumes \(O(n)\) call stack space.

Bottom-Up Tabulation

Iteratively fills an array from smallest subproblem (base cases) upward. Zero call stack overhead, better CPU cache locality, and unlocks dramatic space optimizations.

Essential 1D DP Patterns

1. Include / Exclude (House Robber)

At house \(i\), choose whether to rob house \(i\) (prohibiting house \(i-1\)) or skip it: \[dp[i] = \max(dp[i-1], nums[i] + dp[i-2])\]

2. Unbounded Optimization (Coin Change)

Finding minimum coins to form amount \(a\). Subproblem: take any denomination \(c\) and add 1 to \(dp[a - c]\): \[dp[a] = \min_{c \in coins} (dp[a - c] + 1)\]

2D Grid, String, & Knapsack DP

0/1 Knapsack Problem

Given \(n\) items with values \(v\) and weights \(w\), maximize total value within capacity \(W\): \[dp[i][w] = \begin{cases} dp[i-1][w] & \text{if } w_i > w \\ \max(dp[i-1][w], v_i + dp[i-1][w - w_i]) & \text{if } w_i \le w \end{cases}\]

Longest Common Subsequence (LCS)

Matches characters between two strings \(s_1\) and \(s_2\): \[dp[i][j] = \begin{cases} 1 + dp[i-1][j-1] & \text{if } s_1[i-1] == s_2[j-1] \\ \max(dp[i-1][j], dp[i][j-1]) & \text{otherwise} \end{cases}\]

Space Optimization: 2D to 1D

Because 0/1 Knapsack only references the previous row \(i-1\), we can compress the \(n \times W\) 2D table into a single 1D array of size \(W\) by iterating backwards from \(W\) down to \(w_i\): 

// 0/1 Knapsack in O(W) auxiliary space:
int[] dp = new int[W + 1];
for (int i = 0; i < n; i++) {
    for (int w = W; w >= weights[i]; w--) { // REVERSE traversal prevents reusing same item
        dp[w] = Math.max(dp[w], values[i] + dp[w - weights[i]]);
    }
}
