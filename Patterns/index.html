Mastering Algorithmic Patterns

Coding interviews rarely require inventing brand new algorithms from scratch. Instead, over 85% of LeetCode Medium and Hard problems map directly to a handful of reusable mental models known as Algorithmic Patterns. By internalizing these 10 core blueprints, you transform ambiguous problem statements into immediate, systematic solutions.

1. Two Pointers Pattern

The Two Pointers pattern utilizes two index variables that traverse a linear data structure (Array or String) simultaneously. The pointers can move inwardly towards each other (converging) or in the same direction at different speeds.

Identification Clue: The input array is already sorted (or can be sorted in \(O(N \log N)\) without altering requirements), and you need to find a pair, triplet, or subarray satisfying a sum or partition constraint in \(O(N)\) time instead of \(O(N^2)\).

Canonical Problem: 3Sum (LeetCode 15)

Fix the first element nums[i], then use two converging pointers left = i + 1 and right = n - 1 to find the remaining pair summing to -nums[i] in \(O(N)\) per element. Total time: \(O(N^2)\), Space: \(O(1)\).

ThreeSum.java Two Pointers Template 
import java.util.*;

public class ThreeSum {
    public static List<List<Integer>> threeSum(int[] nums) {
        List<List<Integer>> result = new ArrayList<>();
        Arrays.sort(nums); // Crucial prerequisite: Sort in O(N log N)
        int n = nums.length;

        for (int i = 0; i < n - 2; i++) {
            // Skip duplicates for the fixed first element
            if (i > 0 && nums[i] == nums[i - 1]) continue;

            int left = i + 1;
            int right = n - 1;
            int target = -nums[i];

            while (left < right) {
                int sum = nums[left] + nums[right];
                if (sum == target) {
                    result.add(Arrays.asList(nums[i], nums[left], nums[right]));
                    // Skip duplicates for left and right
                    while (left < right && nums[left] == nums[left + 1]) left++;
                    while (left < right && nums[right] == nums[right - 1]) right--;
                    left++;
                    right--;
                } else if (sum < target) {
                    left++; // Need larger sum
                } else {
                    right--; // Need smaller sum
                }
            }
        }
        return result;
    }
}

2. Fast & Slow Pointers (Floyd's Cycle Finding)

Also known as the Hare & Tortoise Algorithm, this pattern moves two pointers at different speeds (typically slow moves 1 step, fast moves 2 steps) through a sequence or linked structure.

Core Mathematical Invariant: In each iteration inside a cycle of length \(C\), the distance between Fast and Slow decreases by \(2 - 1 = 1\). Therefore, if a cycle exists, Fast will catch up with Slow in at most \(C\) iterations inside the loop!

Finding Cycle Origin (LeetCode 142)

When Slow and Fast meet at distance \(k\) from cycle entrance, reset Slow to head while leaving Fast at collision point. Advance both 1 step at a time; they will collide exactly at the start of the cycle!

DetectCycleStart.java Floyd's Algorithm 
public class DetectCycleStart {
    public static ListNode detectCycle(ListNode head) {
        if (head == null || head.next == null) return null;

        ListNode slow = head;
        ListNode fast = head;

        // Phase 1: Determine if a cycle exists
        while (fast != null && fast.next != null) {
            slow = slow.next;
            fast = fast.next.next;
            if (slow == fast) {
                // Phase 2: Find cycle entrance
                ListNode ptr1 = head;
                ListNode ptr2 = slow;
                while (ptr1 != ptr2) {
                    ptr1 = ptr1.next;
                    ptr2 = ptr2.next;
                }
                return ptr1; // Intersection is the entry node
            }
        }
        return null; // No cycle detected
    }
}

3. Sliding Window Pattern

The Sliding Window pattern is used to perform operations on a specific window size of a given array or string, converting a naive \(O(N \cdot K)\) or \(O(N^2)\) nested loop algorithm into an optimal \(O(N)\) linear pass.

Fixed Size Window
Window size \(K\) remains constant. Add incoming element at right, remove outgoing element at right - K. Example: Max sum subarray of size \(K\).
Time: O(N) · Space: O(1)
Dynamic / Variable Window
Expand right until condition is violated, then contract left until condition is restored. Example: Longest Substring Without Repeating Characters.
Time: O(N) · Space: O(min(N, Σ))
LongestRepeatingReplacement.java LeetCode 424 (Dynamic Window) 
public class LongestRepeatingReplacement {
    public static int characterReplacement(String s, int k) {
        int[] count = new int[26];
        int maxFreq = 0;
        int left = 0;
        int maxLen = 0;

        for (int right = 0; right < s.length(); right++) {
            maxFreq = Math.max(maxFreq, ++count[s.charAt(right) - 'A']);

            // Window length = right - left + 1
            // Replacements needed = (window length) - maxFreq
            while ((right - left + 1) - maxFreq > k) {
                count[s.charAt(left) - 'A']--;
                left++; // Contract window from left
            }

            maxLen = Math.max(maxLen, right - left + 1);
        }
        return maxLen;
    }
}

4. Prefix Sum & Difference Array

Prefix Sum precomputes cumulative sums such that any range sum query \(\sum_{i=L}^{R} A[i]\) can be answered in \(O(1)\) constant time using \(\text{Prefix}[R+1] - \text{Prefix}[L]\).

HashMap + Prefix Sum (Subarray Sum Equals K):
If cumulative sum up to index \(j\) is \(S_j\), we seek an earlier index \(i\) where \(S_j - S_i = k \implies S_i = S_j - k\). Storing prefix sum frequency counts in a HashMap<Integer, Integer> allows detecting all such subarrays in a single \(O(N)\) pass!
SubarraySumK.java LeetCode 560: O(N) Hash Prefix Sum 
import java.util.HashMap;
import java.util.Map;

public class SubarraySumK {
    public static int subarraySum(int[] nums, int k) {
        int count = 0;
        int currentPrefixSum = 0;
        // Map: PrefixSum -> Frequency of occurrence
        Map<Integer, Integer> prefixMap = new HashMap<>();
        prefixMap.put(0, 1); // Base condition: prefix sum of 0 appears once

        for (int num : nums) {
            currentPrefixSum += num;
            // Check if there is an earlier prefix sum that satisfies: currentPrefixSum - earlier = k
            if (prefixMap.containsKey(currentPrefixSum - k)) {
                count += prefixMap.get(currentPrefixSum - k);
            }
            prefixMap.put(currentPrefixSum, prefixMap.getOrDefault(currentPrefixSum, 0) + 1);
        }
        return count;
    }
}

5. Monotonic Stack & Deque

A Monotonic Stack maintains its elements in strictly ascending or descending order. Whenever a new incoming element violates the monotonic invariant, elements are popped from the stack until order is restored.

Key Applications: Next Greater Element, Daily Temperatures, Largest Rectangle in Histogram, Trapping Rain Water, and Sliding Window Maximum (using Monotonic Deque).

DailyTemperatures.java LeetCode 739: Monotonic Decreasing Stack 
import java.util.ArrayDeque;
import java.util.Deque;

public class DailyTemperatures {
    public static int[] dailyTemperatures(int[] temperatures) {
        int n = temperatures.length;
        int[] answer = new int[n];
        // Stack stores indices of temperatures in strictly decreasing order
        Deque<Integer> stack = new ArrayDeque<>();

        for (int i = 0; i < n; i++) {
            // While current temperature is warmer than temperature at stack top
            while (!stack.isEmpty() && temperatures[i] > temperatures[stack.peek()]) {
                int prevIndex = stack.pop();
                answer[prevIndex] = i - prevIndex; // Days waited
            }
            stack.push(i);
        }
        return answer;
    }
}

6. In-place Reversal of Linked List

Frequently asked in interviews (e.g. Reverse Nodes in k-Group, Palindrome Linked List). Reversing pointers without allocating auxiliary heap memory requires maintaining 3 pointer handles: prev, curr, and next.

ReverseSublist.java LeetCode 92: Reverse Between [left, right] 
public class ReverseSublist {
    public static ListNode reverseBetween(ListNode head, int left, int right) {
        if (head == null || left == right) return head;

        ListNode dummy = new ListNode(0);
        dummy.next = head;
        ListNode prev = dummy;

        // Step 1: Reach node at position left - 1
        for (int i = 0; i < left - 1; i++) prev = prev.next;

        // Step 2: Reverse sublist using head insertion
        ListNode curr = prev.next;
        for (int i = 0; i < right - left; i++) {
            ListNode nextTemp = curr.next;
            curr.next = nextTemp.next;
            nextTemp.next = prev.next;
            prev.next = nextTemp;
        }

        return dummy.next;
    }
}

7. Two Heaps Pattern

When dealing with a dynamic stream of numbers where you need to track the median or partition values into lower and upper halves, maintaining two balancing heaps solves the problem with \(O(\log N)\) insertion and \(O(1)\) median retrieval.

The Two Heaps Split:
• Max-Heap (smallHalf): Stores smaller half of numbers. Root contains maximum of lower half.
• Min-Heap (largeHalf): Stores larger half of numbers. Root contains minimum of upper half.
• Size Invariant: smallHalf.size() == largeHalf.size() OR smallHalf.size() == largeHalf.size() + 1.
MedianFinder.java LeetCode 295: Find Median from Data Stream 
import java.util.Collections;
import java.util.PriorityQueue;

public class MedianFinder {
    private PriorityQueue<Integer> smallHalf; // Max-heap
    private PriorityQueue<Integer> largeHalf; // Min-heap

    public MedianFinder() {
        smallHalf = new PriorityQueue<>(Collections.reverseOrder());
        largeHalf = new PriorityQueue<>();
    }

    public void addNum(int num) {
        smallHalf.offer(num);
        largeHalf.offer(smallHalf.poll()); // Balance values

        // Maintain size invariant: smallHalf can have at most 1 more element
        if (smallHalf.size() < largeHalf.size()) {
            smallHalf.offer(largeHalf.poll());
        }
    }

    public double findMedian() {
        if (smallHalf.size() > largeHalf.size()) {
            return smallHalf.peek();
        }
        return (smallHalf.peek() + largeHalf.peek()) / 2.0;
    }
}

8. Top 'K' Elements (Heap & QuickSelect)

Any problem requesting the "K largest", "K smallest", or "K most frequent" elements can be solved using either a bounded Min-Heap of size \(K\) in \(O(N \log K)\), or average linear time \(O(N)\) using QuickSelect.

KthLargest.java LeetCode 215: O(N log K) Min-Heap 
import java.util.PriorityQueue;

public class KthLargest {
    public static int findKthLargest(int[] nums, int k) {
        // Min-heap keeps top K largest elements seen so far
        PriorityQueue<Integer> minHeap = new PriorityQueue<>(k);

        for (int num : nums) {
            minHeap.offer(num);
            if (minHeap.size() > k) {
                minHeap.poll(); // Evict smallest; remaining elements are larger
            }
        }
        return minHeap.peek(); // Root of minHeap is the K-th largest!
    }
}

9. Merge Intervals Pattern

Interval problems deal with overlapping timeframes or ranges. Two intervals \([a, b]\) and \([c, d]\) (with \(a \le c\)) overlap if and only if \(c \le b\). The union of the overlapping intervals is \([a, \max(b, d)]\).

MergeIntervals.java LeetCode 56: Sorting + Linear Sweep 
import java.util.*;

public class MergeIntervals {
    public static int[][] merge(int[][] intervals) {
        if (intervals.length <= 1) return intervals;

        // Step 1: Sort by start time in O(N log N)
        Arrays.sort(intervals, (a, b) -> Integer.compare(a[0], b[0]));

        List<int[]> merged = new ArrayList<>();
        int[] current = intervals[0];
        merged.add(current);

        for (int i = 1; i < intervals.length; i++) {
            int[] next = intervals[i];
            if (next[0] <= current[1]) {
                // Overlap detected: extend end boundary
                current[1] = Math.max(current[1], next[1]);
            } else {
                // Disjoint interval: start a new interval
                current = next;
                merged.add(current);
            }
        }
        return merged.toArray(new int[merged.size()][]);
    }
}

10. Modified Binary Search

Whenever a problem presents an array that is sorted, rotated sorted, bitonic, or has monotonic properties (\(F(x) = \text{true} \implies F(x+1) = \text{true}\)), Binary Search cuts the search space in half each iteration in \(O(\log N)\).

RotatedBinarySearch.java LeetCode 33: Search in Rotated Sorted Array 
public class RotatedBinarySearch {
    public static int search(int[] nums, int target) {
        int low = 0, high = nums.length - 1;

        while (low <= high) {
            int mid = low + (high - low) / 2;
            if (nums[mid] == target) return mid;

            // Check if left half is normally sorted
            if (nums[low] <= nums[mid]) {
                if (target >= nums[low] && target < nums[mid]) {
                    high = mid - 1; // Target lies in left sorted half
                } else {
                    low = mid + 1; // Target in right half
                }
            } else { // Right half is normally sorted
                if (target > nums[mid] && target <= nums[high]) {
                    low = mid + 1; // Target lies in right sorted half
                } else {
                    high = mid - 1; // Target in left half
                }
            }
        }
        return -1; // Target not found
    }
}

30-Second Pattern Identification Guide

When presented with an interview problem, evaluate this decision matrix against the problem statement's keywords and constraints:

If the problem asks for... And contains constraints like... Target Algorithmic Pattern
Pair / Triplet with target sum or water trapping Sorted array or can sort without penalty Two Pointers
Cycle detection or middle node Singly linked list or cyclic number transformation Fast & Slow Pointers
Longest / Shortest contiguous subarray or substring Target sum, at most K distinct, no duplicates Sliding Window
Subarray sum equals K or range query sum Array with positive & negative numbers Prefix Sum + HashMap
Next greater / smaller element or stock span Finding boundary elements in linear time Monotonic Stack
Continuous median or dynamic top 50 percentile Streaming numbers arriving one by one Two Heaps
Kth largest, most frequent, or closest elements Large dataset, only top K required Top K (Min-Heap / QuickSelect)
Overlapping meetings, non-overlapping intervals Interval start & end times [start, end] Merge Intervals
Search in \(O(\log N)\) or find minimum bound Rotated sorted array or monotonic condition Modified Binary Search
