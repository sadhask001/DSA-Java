Queue Fundamentals

The FIFO Principle: First-In, First-Out

A Queue is a linear data structure following the FIFO (First In, First Out) order. The element inserted first is always the first one to be removed.

🌍 Real-World Analogies:
  • A movie ticket checkout counter line (first person in line gets served first).
  • Printer spooler queue (documents print in the order submitted).
  • Web server request processing queues (handling traffic spikes sequentially).
  • Breadth-First Search (BFS) level-order traversal buffer.

Front & Rear Pointers

A queue maintains two boundary pointers:

  • Front: The head of the queue where elements are removed (dequeue).
  • Rear: The tail of the queue where elements are inserted (enqueue).

The Linear Queue Limitation

In a naive array-based queue, once rear reaches the end of the array, no new elements can be added even if elements were dequeued from the front. This is called False Overflow.

Solved by Circular Queue!

Core Operations ($O(1)$ Time)

Queue API Operations Specification

Method Signature Description Throws Exception Returns Special Value
Insert Adds an element to the rear of the queue. add(e) offer(e) → false
Remove Retrieves and removes the front element. remove() poll() → null
Examine Retrieves without removing the front element. element() peek() → null

Circular Queue Architecture

Modulo Ring Arithmetic

A Circular Queue connects the last position back to the first position. When rear reaches capacity - 1, it wraps around to index 0 using the modulo operator: rear = (rear + 1) % capacity.

public class MyCircularQueue {
    private int[] data;
    private int front;
    private int rear;
    private int size;
    private int capacity;

    public MyCircularQueue(int k) {
        this.capacity = k;
        this.data = new int[k];
        this.front = 0;
        this.rear = -1;
        this.size = 0;
    }

    public boolean enQueue(int value) {
        if (isFull()) return false;
        rear = (rear + 1) % capacity; // Wrap around
        data[rear] = value;
        size++;
        return true;
    }

    public boolean deQueue() {
        if (isEmpty()) return false;
        front = (front + 1) % capacity; // Advance front
        size--;
        return true;
    }

    public int Front() { return isEmpty() ? -1 : data[front]; }
    public int Rear() { return isEmpty() ? -1 : data[rear]; }
    public boolean isEmpty() { return size == 0; }
    public boolean isFull() { return size == capacity; }
}

Double-Ended Queue (Deque)

Insertion and Deletion at Both Ends

A Deque (pronounced "deck") allows insertion and removal at both the Front and Rear in strictly $O(1)$ time. It acts as both a Queue and a Stack simultaneously!

Front Operations

  • addFirst(e) / offerFirst(e)
  • removeFirst() / pollFirst()
  • getFirst() / peekFirst()

Rear Operations

  • addLast(e) / offerLast(e)
  • removeLast() / pollLast()
  • getLast() / peekLast()

Priority Queue

Heap-Based Ordering

In a PriorityQueue, elements are dequeued based on their priority rather than their arrival order. In Java, PriorityQueue is implemented as a Binary Min-Heap by default (smallest value has highest priority).

// Default Min-Heap (Smallest element at head)
PriorityQueue<Integer> minHeap = new PriorityQueue<>();

// Max-Heap using reverse order Comparator
PriorityQueue<Integer> maxHeap = new PriorityQueue<>(Collections.reverseOrder());

minHeap.offer(30);
minHeap.offer(10);
minHeap.offer(20);

System.out.println(minHeap.poll()); // 10 (smallest first!)
System.out.println(minHeap.poll()); // 20
System.out.println(minHeap.poll()); // 30
Insertion: O(log n) | Removal: O(log n) | Peek: O(1)

Linked List-Based Queue Implementation

Dynamic Queue via Node Pointers

public class LinkedListQueue<T> {
    private static class Node<T> {
        T data;
        Node<T> next;
        Node(T data) { this.data = data; }
    }

    private Node<T> front = null;
    private Node<T> rear = null;
    private int size = 0;

    public void enqueue(T item) {
        Node<T> newNode = new Node<>(item);
        if (rear == null) {
            front = rear = newNode;
        } else {
            rear.next = newNode;
            rear = newNode;
        }
        size++;
    }

    public T dequeue() {
        if (front == null) throw new NoSuchElementException("Queue empty!");
        T data = front.data;
        front = front.next;
        if (front == null) rear = null;
        size--;
        return data;
    }

    public T peek() {
        if (front == null) throw new NoSuchElementException("Queue empty!");
        return front.data;
    }

    public boolean isEmpty() { return front == null; }
    public int size() { return size; }
}

Applications: Breadth-First Search (BFS)

Level-Order Binary Tree Traversal via Queue

Queues are the quintessential data structure for BFS algorithms on graphs and trees because they process nodes level-by-level in expanding ripples.

public List<List<Integer>> levelOrder(TreeNode root) {
    List<List<Integer>> result = new ArrayList<>();
    if (root == null) return result;

    Queue<TreeNode> queue = new ArrayDeque<>();
    queue.offer(root);

    while (!queue.isEmpty()) {
        int levelSize = queue.size();
        List<Integer> currentLevel = new ArrayList<>();

        for (int i = 0; i < levelSize; i++) {
            TreeNode node = queue.poll();
            currentLevel.add(node.val);

            if (node.left != null) queue.offer(node.left);
            if (node.right != null) queue.offer(node.right);
        }
        result.add(currentLevel);
    }
    return result;
}
