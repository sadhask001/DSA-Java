Linked List Fundamentals

What is a Linked List?

A Linked List is a linear, dynamic data structure where elements are not stored in contiguous physical memory locations. Instead, each element is an independent object called a Node on the Java Heap, connected together by memory references (pointers).

💡 Key Advantage: Dynamic size without contiguous memory constraints! Inserting or deleting at the head is strictly O(1) without shifting elements, unlike static arrays or ArrayList.

The Anatomy of a Node

A standard Singly Linked List Node holds two pieces of data:

  • Data Payload: The value stored (e.g., int data).
  • Next Reference: A reference pointer holding the memory address of the next Node (Node next), or null if it's the tail.

Standard Java Node Definition

class Node {
    int data;       // Element value
    Node next;      // Reference to next node

    Node(int data) {
        this.data = data;
        this.next = null;
    }
}

Singly Linked List (SLL)

Unidirectional Linear Traversal

In a Singly Linked List, navigation only proceeds in one forward direction: from head towards the tail (which points to null).

[HEAD: 0x1000] ──> Node(10 | 0x2000) ──> Node(20 | 0x3000) ──> Node(30 | null) ──> NULL

Traversing an SLL

Start at head and advance the pointer until it reaches null:

Node curr = head;
while (curr != null) {
    System.out.print(curr.data + " -> ");
    curr = curr.next; // Advance
}
System.out.println("null");
Time: O(N) | Space: O(1)

Insert at Head (O(1))

Create a new node, point its next to the current head, then update head:

public Node insertAtHead(Node head, int val) {
    Node newNode = new Node(val);
    newNode.next = head;
    return newNode; // New head!
}
Time: O(1) | Space: O(1)

Doubly Linked List (DLL)

Bidirectional Traversal

A Doubly Linked List node contains two references: one pointing to the next node, and another pointing to the previous node. This allows forward and backward traversal.

NULL <── Node(10) <═══> Node(20) <═══> Node(30) ──> NULL
           ▲                               ▲
         [HEAD]                          [TAIL]

Doubly Node Blueprint

class DoublyNode {
    int data;
    DoublyNode prev;
    DoublyNode next;

    DoublyNode(int data) {
        this.data = data;
        this.prev = null;
        this.next = null;
    }
}

Advantages & Trade-offs

  • O(1) Deletion when given pointer to the node to delete (no need to find previous node!).
  • Bidirectional navigation (vital for LRU Cache, Deque, Browser History).
  • Memory Overhead: Extra 8-byte reference per node for prev.

Circular Linked Lists (CLL & CDLL)

Endless Loop Structures

In a Circular Linked List, the last node's next pointer does not point to null; instead, it points back to the head node, forming a closed ring.

Circular Singly (CLL)

Tail node points to head: tail.next == head. Common in CPU round-robin task schedulers and multiplayer board game turns.

Node curr = head;
do {
    System.out.print(curr.data + " ");
    curr = curr.next;
} while (curr != head);

Circular Doubly (CDLL)

head.prev points directly to tail, and tail.next points directly to head. Provides instant O(1) access to both ends with zero null-checks!

Head & Tail Access: O(1)

Memory Model: Array vs Linked List

Contiguous vs Non-Contiguous Allocation

Understanding where bits live in hardware explains why arrays and linked lists have radically different real-world execution speeds.

Architecture Dimension Array / ArrayList Linked List
Physical Memory Contiguous consecutive bytes Scattered across Heap addresses
CPU Cache Locality High (L1/L2 prefetching loads neighboring elements) Poor (Frequent cache misses following pointer hops)
Memory Overhead Low (just elements + array header) High (Each node has 16B object header + 8B pointer(s))
Resizing Friction Requires new allocation & O(n) element copy Zero (Heap simply allocates a single new node)

Core Operations Implementation

Complete Java Singly Linked List Implementation

public class SinglyLinkedList {
    private Node head;
    private int size;

    // 1. Insert at Head: O(1)
    public void addFirst(int val) {
        Node newNode = new Node(val);
        newNode.next = head;
        head = newNode;
        size++;
    }

    // 2. Insert at Tail: O(n) without tail pointer, O(1) with tail
    public void addLast(int val) {
        Node newNode = new Node(val);
        if (head == null) {
            head = newNode;
        } else {
            Node curr = head;
            while (curr.next != null) {
                curr = curr.next;
            }
            curr.next = newNode;
        }
        size++;
    }

    // 3. Delete Head: O(1)
    public int removeFirst() {
        if (head == null) throw new NoSuchElementException();
        int val = head.data;
        head = head.next;
        size--;
        return val;
    }

    // 4. Delete by Value: O(n)
    public boolean remove(int key) {
        if (head == null) return false;
        if (head.data == key) {
            head = head.next;
            size--;
            return true;
        }
        Node curr = head;
        while (curr.next != null && curr.next.data != key) {
            curr = curr.next;
        }
        if (curr.next != null) {
            curr.next = curr.next.next; // Bypass deleted node
            size--;
            return true;
        }
        return false;
    }
}

Reversing a Linked List

The Canonical Three-Pointer In-Place Inversion

Reversing an SLL in place requires three pointers: prev, curr, and next. At each step, we preserve the future node, redirect curr.next backward to prev, and slide all three pointers forward.

public Node reverseList(Node head) {
    Node prev = null;
    Node curr = head;

    while (curr != null) {
        Node next = curr.next; // 1. Save next node
        curr.next = prev;      // 2. Reverse link
        prev = curr;           // 3. Move prev forward
        curr = next;           // 4. Move curr forward
    }

    return prev; // prev is the new head!
}
Complexity: Time: O(N) (single pass) | Auxiliary Space: O(1) (only 3 reference variables).

Cycle Detection & Fast/Slow Pointers

Floyd's Tortoise and Hare Algorithm

Two pointers start at the head: slow moves 1 step per turn, while fast moves 2 steps per turn. If a cycle exists, fast will lap and collide with slow inside the loop. If fast reaches null, no cycle exists.

public boolean hasCycle(Node head) {
    if (head == null || head.next == null) return false;

    Node slow = head;
    Node fast = head;

    while (fast != null && fast.next != null) {
        slow = slow.next;         // 1 step
        fast = fast.next.next;    // 2 steps

        if (slow == fast) {
            return true; // Pointers collided -> Cycle detected!
        }
    }

    return false; // Reached end -> No cycle
}

Finding Middle of List

When fast reaches the end, slow is exactly at the midpoint:

Node slow = head, fast = head;
while (fast != null && fast.next != null) {
    slow = slow.next;
    fast = fast.next.next;
}
return slow; // Middle node!

Cycle Starting Node Entry

After collision, reset one pointer to head. Advance both at 1 step each; they will meet exactly at the cycle entrance!

Time: O(N) | Space: O(1)

Array vs ArrayList vs LinkedList

Operational Complexity Comparison

Operation Array (Primitive) ArrayList (Java) LinkedList (Singly / Doubly)
Access by Index O(1) O(1) O(n) (must traverse)
Insert at Head N/A (Fixed size) O(n) (shift all) O(1)
Insert at Tail N/A O(1) amortized O(1) (with tail pointer)
Delete at Head N/A O(n) (shift left) O(1)
Search by Value O(n) O(n) O(n)
