Tree Terminology & Core Formulas

What is a Tree?

A Tree is a non-linear, hierarchical data structure composed of nodes connected by directed edges. Unlike arrays and linked lists which represent linear sequences, trees represent organizational hierarchies like file directory structures, DOM elements, and abstract syntax trees.

Essential Definitions

  • Root: The top-most node without any parent.
  • Leaf Node: A node having zero children.
  • Depth of a Node: Length of path from root to that node.
  • Height of a Tree: Maximum number of edges from root to a leaf.
  • Degree: The number of children a node possesses.

Mathematical Properties

  • Max nodes at level $i$: $2^i$ (root is at level 0).
  • Max nodes in tree of height $h$: $2^{h+1} - 1$.
  • Min height with $n$ nodes: $\lceil \log_2(n+1) \rceil - 1$.
  • A tree with $n$ nodes has exactly $n - 1$ edges.

Classifications of Binary Trees

Standard Structural Variations

1. Full Binary Tree

Every node has either 0 or 2 children. No node has exactly one child.

2. Complete Binary Tree

All levels are completely filled except possibly the last, and the last level is filled from left to right without gaps. (Critical for Binary Heaps!).

3. Perfect Binary Tree

All internal nodes have 2 children, and all leaves are at the exact same depth level.

4. Degenerate / Skewed Tree

Every internal node has only one child. The tree degrades into a Linked List with $O(n)$ time complexity.

Tree Traversals (DFS & BFS)

Depth-First Search (DFS) & Breadth-First Search (BFS)

Unlike linear structures which only have one logical order, trees can be traversed in multiple distinct directions.

Inorder Traversal (L → Root → R)

For a BST, Inorder traversal visits nodes in strictly ascending sorted order!

void inorder(TreeNode root) {
    if (root == null) return;
    inorder(root.left);
    System.out.print(root.val + " ");
    inorder(root.right);
}

Preorder Traversal (Root → L → R)

Used to serialize / copy a tree structure.

void preorder(TreeNode root) {
    if (root == null) return;
    System.out.print(root.val + " ");
    preorder(root.left);
    preorder(root.right);
}

Postorder Traversal (L → R → Root)

Used for bottom-up operations like deleting a tree or calculating tree height.

void postorder(TreeNode root) {
    if (root == null) return;
    postorder(root.left);
    postorder(root.right);
    System.out.print(root.val + " ");
}

Level-Order Traversal (BFS)

Visits nodes level-by-level using a FIFO Queue buffer.

Queue<TreeNode> q = new ArrayDeque<>();
q.offer(root);
while (!q.isEmpty()) {
    TreeNode curr = q.poll();
    System.out.print(curr.val + " ");
    if (curr.left != null) q.offer(curr.left);
    if (curr.right != null) q.offer(curr.right);
}

Binary Search Tree (BST)

The BST Invariant Property

For every node $X$ in a Binary Search Tree: all values in the left subtree are strictly smaller than $X$, and all values in the right subtree are strictly greater than $X$.

public class BST {
    static class Node {
        int val;
        Node left, right;
        Node(int val) { this.val = val; }
    }

    // 1. Search: O(h)
    public boolean search(Node root, int target) {
        if (root == null) return false;
        if (root.val == target) return true;
        return target < root.val ? search(root.left, target) : search(root.right, target);
    }

    // 2. Insert: O(h)
    public Node insert(Node root, int val) {
        if (root == null) return new Node(val);
        if (val < root.val) root.left = insert(root.left, val);
        else if (val > root.val) root.right = insert(root.right, val);
        return root;
    }

    // 3. Delete: O(h) with 3 Cases
    public Node delete(Node root, int key) {
        if (root == null) return null;
        if (key < root.val) root.left = delete(root.left, key);
        else if (key > root.val) root.right = delete(root.right, key);
        else {
            // Case 1 & 2: 0 or 1 child
            if (root.left == null) return root.right;
            if (root.right == null) return root.left;
            // Case 3: 2 children -> replace with Inorder Successor (min in right subtree)
            Node successor = findMin(root.right);
            root.val = successor.val;
            root.right = delete(root.right, successor.val);
        }
        return root;
    }

    private Node findMin(Node node) {
        while (node.left != null) node = node.left;
        return node;
    }
}

Self-Balancing: AVL Trees

Balance Factor & Rotations

An AVL Tree is a self-balancing BST where the difference between heights of left and right subtrees for any node cannot exceed 1: $$\text{Balance Factor} = \text{Height}(\text{Left}) - \text{Height}(\text{Right}) \in \{-1, 0, 1\}$$

The 4 Rotation Types

  • LL Rotation: Single Right Rotation when left-child of left-child causes imbalance.
  • RR Rotation: Single Left Rotation when right-child of right-child causes imbalance.
  • LR Rotation: Left rotation on left child, then Right rotation on root.
  • RL Rotation: Right rotation on right child, then Left rotation on root.

Guarantee

Because height is strictly maintained at $\le 1.44 \log_2 n$, Search, Insert, and Delete are guaranteed to run in strictly $O(\log n)$ worst-case time.

Red-Black Trees in Java

Java Collections Framework Standard

A Red-Black Tree is a self-balancing BST where each node contains an extra color bit (Red or Black). Java's standard java.util.TreeMap and java.util.TreeSet are implemented as Red-Black Trees!

The 5 Red-Black Invariant Rules:
  1. Every node is either RED or BLACK.
  2. The root node is always BLACK.
  3. Every leaf (NIL null pointer) is considered BLACK.
  4. If a node is RED, both of its children must be BLACK (no two consecutive RED nodes).
  5. Every simple path from any node to its descendant leaves contains the same number of BLACK nodes (Black Height).
