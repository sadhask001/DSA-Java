Binary Heap Fundamentals

What is a Binary Heap?

A Binary Heap is a Complete Binary Tree that satisfies the Heap Property:

  • Min-Heap: The key of every node is $\le$ the keys of its children. The minimum element is always at the Root!
  • Max-Heap: The key of every node is $\ge$ the keys of its children. The maximum element is always at the Root!
⚡ Why Heaps are Unique: Because a Binary Heap is a complete binary tree (all levels filled except possibly the last, which is filled from left to right), it requires zero node pointers! It is stored efficiently in a simple flat 1D array.

Array Representation & Index Math

0-Based Array Formulas

For any node at index $i$ in a 0-indexed array:

Parent & Child Formulas

Parent(i)     = (i - 1) / 2
LeftChild(i)  = 2 * i + 1
RightChild(i) = 2 * i + 2

Leaf Node Range

In a heap of size $n$, leaf nodes reside in the index range:

Leaves = [floor(n / 2), n - 1]
Zero Pointer Overhead!

Core Operations Implementation

1. Insertion ($O(\log n)$ Time via Sift-Up)

Append the new value at the end of the array (preserving the complete tree shape), then bubble/sift it up until the heap property is restored.

public void insert(int val) {
    heap.add(val); // Append at end
    int curr = heap.size() - 1;

    // Sift-Up
    while (curr > 0) {
        int parent = (curr - 1) / 2;
        if (heap.get(curr) < heap.get(parent)) { // Min-heap condition
            swap(curr, parent);
            curr = parent;
        } else {
            break;
        }
    }
}

2. Extract Min / Max ($O(\log n)$ Time via Sift-Down)

The root contains the target extreme element. Replace root with the last element in the array, remove the last element, and sift down the new root.

public int extractMin() {
    if (heap.isEmpty()) throw new NoSuchElementException();
    int min = heap.get(0);

    int lastVal = heap.remove(heap.size() - 1);
    if (!heap.isEmpty()) {
        heap.set(0, lastVal);
        siftDown(0);
    }
    return min;
}

private void siftDown(int i) {
    int size = heap.size();
    while (2 * i + 1 < size) {
        int smallest = 2 * i + 1; // Left child
        int right = 2 * i + 2;

        if (right < size && heap.get(right) < heap.get(smallest)) {
            smallest = right;
        }

        if (heap.get(smallest) < heap.get(i)) {
            swap(i, smallest);
            i = smallest;
        } else {
            break;
        }
    }
}

Building a Heap: $O(n)$ Heapify

Bottom-Up Heap Construction

Inserting $n$ elements one by one takes $O(n \log n)$ time. However, building a heap in-place from an existing unsorted array takes only $O(n)$ time by running siftDown() starting from the last non-leaf node up to the root! 

public static void buildHeap(int[] arr) {
    int n = arr.length;
    // Start from the last internal node: (n / 2) - 1 down to 0
    for (int i = (n / 2) - 1; i >= 0; i--) {
        heapify(arr, n, i);
    }
}
Mathematical Proof: Most nodes are near the bottom of the tree and move down at most 1 or 2 levels. The infinite series $\sum_{h=0}^{\infty} \frac{h}{2^h} = 2$ proves that total operations are bounded by $2n = O(n)$.

Heap Sort Algorithm

In-Place $O(n \log n)$ Sorting

1. Build a Max-Heap ($O(n)$).
2. Repeatedly swap root (maximum) with the last unsorted index, reduce heap size by 1, and heapify the root ($n \times O(\log n)$).

public static void heapSort(int[] arr) {
    int n = arr.length;

    // 1. Build Max-Heap
    for (int i = n / 2 - 1; i >= 0; i--) {
        heapify(arr, n, i);
    }

    // 2. Extract elements one by one
    for (int i = n - 1; i > 0; i--) {
        // Move current root to end
        int temp = arr[0];
        arr[0] = arr[i];
        arr[i] = temp;

        // Call max-heapify on reduced heap
        heapify(arr, i, 0);
    }
}

Essential Pattern: Two-Heap Stream Median

Dynamic Median Finding in $O(\log n)$ Time

Split the incoming stream into two halves: a Max-Heap storing the smaller half, and a Min-Heap storing the larger half. The median is always accessible in strictly $O(1)$ time from the roots!

class MedianFinder {
    private PriorityQueue<Integer> smallMaxHeap = new PriorityQueue<>(Collections.reverseOrder());
    private PriorityQueue<Integer> largeMinHeap = new PriorityQueue<>();

    public void addNum(int num) {
        smallMaxHeap.offer(num);
        largeMinHeap.offer(smallMaxHeap.poll());

        if (largeMinHeap.size() > smallMaxHeap.size()) {
            smallMaxHeap.offer(largeMinHeap.poll());
        }
    }

    public double findMedian() {
        if (smallMaxHeap.size() > largeMinHeap.size()) {
            return smallMaxHeap.peek();
        }
        return (smallMaxHeap.peek() + largeMinHeap.peek()) / 2.0;
    }
}
