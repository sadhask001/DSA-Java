Irrevocable Decisions

Mastering Greedy Algorithms

A greedy algorithm constructs a solution piece-by-piece, always choosing the next piece that offers the most immediate, local benefit. Learn when the Greedy Choice Property guarantees global optimality and when it leads to suboptimal traps.

The Two Mandatory Greedy Conditions

1. Greedy Choice Property

A globally optimal solution can be arrived at by making a series of locally optimal choices. Crucially, the choice made at step \(k\) never has to be reconsidered or backtracked based on future decisions.

2. Optimal Substructure

An optimal solution to the overall problem contains within it optimal solutions to the remaining subproblems that exist after the greedy decision is made.

Greedy vs Dynamic Programming

Greedy Approach

Makes one irrevocable choice per step without exploring subproblem alternatives. Typically \(O(n \log n)\) (dominated by sorting) and \(O(1)\) auxiliary memory.

Dynamic Programming

Solves and compares all possible overlapping choices to select the best. Typically \(O(n^2)\) or \(O(n \cdot W)\) with table memory.

The Classic Counterexample: In 0/1 Knapsack, greedy by value/weight fails because unused capacity cannot be filled with partial items. DP is required! But in Fractional Knapsack, greedy by value/weight guarantees the global optimum!

Activity Selection (Interval Scheduling)

Given \(n\) activities with start and finish times, select the maximum number of mutually compatible activities.

The Greedy Rule: Sort by Earliest Finish Time

Picking the activity that finishes earliest frees up the maximum possible remaining time for subsequent activities. 

public int eraseOverlapIntervals(int[][] intervals) {
    if (intervals.length == 0) return 0;
    Arrays.sort(intervals, (a, b) -> Integer.compare(a[1], b[1])); // Sort by end time

    int countNonOverlap = 1;
    int lastEnd = intervals[0][1];

    for (int i = 1; i < intervals.length; i++) {
        if (intervals[i][0] >= lastEnd) {
            countNonOverlap++;
            lastEnd = intervals[i][1];
        }
    }
    return intervals.length - countNonOverlap; // Minimum intervals to remove
}

Reachability & Circular Tour Archetypes

Jump Game I & II

Track the furthest reachable index: maxReach = Math.max(maxReach, i + nums[i]). If \(i > \text{maxReach}\), forward progress is blocked. In Jump Game II, advance jump count only when \(i\) reaches the boundary of the current jump reach.

Gas Station (LeetCode 134)

If total gas \(\ge\) total cost, a solution is guaranteed. Accumulate running tank \(tank += gas[i] - cost[i]\). If \(tank < 0\), none of the stations from the previous start to \(i\) can possibly be the starting station. Reset start to \(i + 1\) and reset \(tank = 0\)!
