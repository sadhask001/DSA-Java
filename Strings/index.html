Java String Architecture & Immutability

In Java, java.lang.String is immutable. Once a String object is instantiated on the heap, its byte/char sequence can never be altered.

Why Immutability?

Security: Strings represent database URLs, network sockets, and passwords.
Thread-Safety: Immutable objects are intrinsically thread-safe without synchronization locks.
Hashcode Caching: Hash code is computed once and cached in private int hash.

String Constant Pool (SCP)

Literal strings like "apple" reside in the String Pool inside Java Heap. If another literal "apple" is declared, the JVM reuses the existing pointer instead of creating duplicates. Calling str.intern() forces pooling.

Knuth-Morris-Pratt (KMP) Algorithm

Naive pattern matching takes \(O(n \cdot m)\) because every mismatch rewinds the text pointer i back to i - j + 1. KMP achieves guaranteed linear \(O(n + m)\) time by never rewinding text pointer i!

The LPS (Longest Prefix Suffix) Table

lps[j] stores the length of the longest proper prefix of pattern[0..j] that is also a suffix of pattern[0..j]. When mismatch happens at pattern[j], the pattern pointer skips directly to j = lps[j - 1]. 

public static int kmpSearch(String text, String pat) {
    int n = text.length(), m = pat.length();
    if (m == 0) return 0;

    int[] lps = computeLPS(pat);
    int i = 0, j = 0;

    while (i < n) {
        if (text.charAt(i) == pat.charAt(j)) {
            i++; j++;
            if (j == m) return i - j; // Match found!
        } else {
            if (j != 0) j = lps[j - 1]; // Fallback without rewinding i
            else i++;
        }
    }
    return -1;
}

private static int[] computeLPS(String pat) {
    int[] lps = new int[pat.length()];
    int len = 0, i = 1;
    while (i < pat.length()) {
        if (pat.charAt(i) == pat.charAt(len)) {
            len++;
            lps[i++] = len;
        } else {
            if (len != 0) len = lps[len - 1];
            else lps[i++] = 0;
        }
    }
    return lps;
}

Rabin-Karp Rolling Hash

Computes a polynomial hash for pattern and a sliding window of text of size \(m\). In \(O(1)\), shifts the window by subtracting the outgoing leftmost character and appending the incoming rightmost character modulo a prime \(Q\).

newHash = (oldHash - text[i] * d^(m-1)) * d + text[i + m] (mod Q)

Trie (Prefix Tree)

A tree-based structure specifically engineered for dictionary storage, auto-completion, and prefix queries. 

public class Trie {
    private static class TrieNode {
        TrieNode[] children = new TrieNode[26];
        boolean isWord = false;
    }

    private final TrieNode root = new TrieNode();

    public void insert(String word) {
        TrieNode curr = root;
        for (char c : word.toCharArray()) {
            int idx = c - 'a';
            if (curr.children[idx] == null) curr.children[idx] = new TrieNode();
            curr = curr.children[idx];
        }
        curr.isWord = true;
    }

    public boolean startsWith(String prefix) {
        TrieNode curr = root;
        for (char c : prefix.toCharArray()) {
            int idx = c - 'a';
            if (curr.children[idx] == null) return false;
            curr = curr.children[idx];
        }
        return true;
    }
}
