Graph Fundamentals & Terminology

What is a Graph?

A Graph is a non-linear data structure consisting of a finite set of Vertices ($V$) (or nodes) and a collection of Edges ($E$) connecting pairs of vertices: $G = (V, E)$.

Direction & Cycles

  • Undirected Graph: Edges are bidirectional ($u - v$).
  • Directed Graph (Digraph): Edges have a direction ($u \to v$).
  • DAG (Directed Acyclic Graph): Directed with no cycles (crucial for build systems, git commits, task dependencies).

Weights & Degrees

  • Weighted: Each edge has an associated numerical cost/distance.
  • In-degree: Count of edges entering a vertex.
  • Out-degree: Count of edges leaving a vertex.

Graph Representations in Java

1. Adjacency Matrix ($V \times V$ 2D Array)

Space: $O(V^2)$. Fast $O(1)$ query to test if edge $(u, v)$ exists, but wastes memory for sparse graphs.

int V = 5;
int[][] adjMatrix = new int[V][V];
// Add edge (u, v) with weight w
adjMatrix[u][v] = w;
adjMatrix[v][u] = w; // If undirected

2. Adjacency List (Industry Standard)

Space: $O(V + E)$. An array of lists storing only actual existing edges. Optimal for sparse graphs.

int V = 5;
List<List<Integer>> adj = new ArrayList<>();
for (int i = 0; i < V; i++) adj.add(new ArrayList<>());

// Add edge u -> v
adj.get(u).add(v);
adj.get(v).add(u); // If undirected

Graph Traversals: BFS & DFS

1. Breadth-First Search (BFS) via Queue

Explores neighbors level-by-level in concentric rings. Computes the shortest path in unweighted graphs.

public void bfs(int start, List<List<Integer>> adj, int V) {
    boolean[] visited = new boolean[V];
    Queue<Integer> queue = new ArrayDeque<>();

    visited[start] = true;
    queue.offer(start);

    while (!queue.isEmpty()) {
        int u = queue.poll();
        System.out.print(u + " ");

        for (int v : adj.get(u)) {
            if (!visited[v]) {
                visited[v] = true;
                queue.offer(v);
            }
        }
    }
}

2. Depth-First Search (DFS) via Recursion

Explores as deep as possible along each branch before backtracking. Used for connected components, path finding, and topological sorting.

public void dfs(int u, List<List<Integer>> adj, boolean[] visited) {
    visited[u] = true;
    System.out.print(u + " ");

    for (int v : adj.get(u)) {
        if (!visited[v]) {
            dfs(v, adj, visited);
        }
    }
}

Cycle Detection

1. In Undirected Graph (Parent Pointer)

During DFS traversal, if a neighbor is already visited and is not the direct parent, a cycle exists.

2. In Directed Graph (3-Color DFS States)

  • 0 (UNVISITED): Node not yet reached.
  • 1 (VISITING): Node is on the current DFS recursive call stack! If an edge leads back to state 1, a Back Edge / Cycle is found!
  • 2 (VISITED): Node and all descendants fully explored.

Topological Sort (Kahn's Algorithm)

Linear Dependency Ordering for DAGs

A linear ordering of vertices such that for every directed edge $u \to v$, vertex $u$ comes before $v$. Only exists for DAGs.

public int[] topologicalSort(int V, List<List<Integer>> adj) {
    int[] inDegree = new int[V];
    for (int u = 0; u < V; u++) {
        for (int v : adj.get(u)) inDegree[v]++;
    }

    Queue<Integer> q = new ArrayDeque<>();
    for (int i = 0; i < V; i++) {
        if (inDegree[i] == 0) q.offer(i);
    }

    int[] order = new int[V];
    int idx = 0;

    while (!q.isEmpty()) {
        int u = q.poll();
        order[idx++] = u;

        for (int v : adj.get(u)) {
            if (--inDegree[v] == 0) q.offer(v);
        }
    }

    // If idx != V, the graph contains a cycle!
    return idx == V ? order : new int[0];
}

Dijkstra's Shortest Path Algorithm

Single-Source Shortest Path (Non-Negative Weights)

Greedy algorithm utilizing a Min-Heap / PriorityQueue to always settle the vertex with the minimum tentative distance.

static class Edge {
    int to, weight;
    Edge(int to, int weight) { this.to = to; this.weight = weight; }
}

public int[] dijkstra(int start, List<List<Edge>> adj, int V) {
    int[] dist = new int[V];
    Arrays.fill(dist, Integer.MAX_VALUE);
    dist[start] = 0;

    // Pair of {node, distance}
    PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> a[1] - b[1]);
    pq.offer(new int[]{start, 0});

    while (!pq.isEmpty()) {
        int[] curr = pq.poll();
        int u = curr[0];
        int d = curr[1];

        if (d > dist[u]) continue; // Stale queue entry

        for (Edge e : adj.get(u)) {
            if (dist[u] + e.weight < dist[e.to]) {
                dist[e.to] = dist[u] + e.weight;
                pq.offer(new int[]{e.to, dist[e.to]});
            }
        }
    }
    return dist;
}
Time Complexity: O((V + E) log V)

Disjoint Set Union (DSU / Union-Find)

Near $O(1)$ Dynamic Connectivity

Tracks partitioned sets. With Path Compression and Union by Rank, operations run in nearly $O(1)$ amortized time ($\alpha(n)$ Inverse Ackermann function).

class DSU {
    int[] parent, rank;

    public DSU(int n) {
        parent = new int[n];
        rank = new int[n];
        for (int i = 0; i < n; i++) parent[i] = i;
    }

    public int find(int i) {
        if (parent[i] == i) return i;
        return parent[i] = find(parent[i]); // Path compression!
    }

    public boolean union(int x, int y) {
        int rootX = find(x);
        int rootY = find(y);
        if (rootX == rootY) return false; // Already connected -> Cycle!

        // Union by rank
        if (rank[rootX] < rank[rootY]) parent[rootX] = rootY;
        else if (rank[rootX] > rank[rootY]) parent[rootY] = rootX;
        else {
            parent[rootY] = rootX;
            rank[rootX]++;
        }
        return true;
    }
}
